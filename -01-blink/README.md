# Blink

## What I Made

I made an Arduino program that makes the built-in LED blink every second.

## What I Learned

- `setup()` runs once when the Arduino starts.
- `loop()` runs repeatedly.
- `pinMode()` sets a pin as an input or output.
- `digitalWrite()` turns the LED on or off.
- `delay(1000)` pauses the program for 1 second.
